# MyFinanzas Backend

Backend API for MyFinanzas.

## Stack

- Python
- FastAPI

## Development

Create virtual environment:

python -m venv .venv

Activate:

.\.venv\Scripts\Activate.ps1

Install dependencies:

pip install -r requirements.txt

Run development server:

fastapi dev app/main.py

API:

http://127.0.0.1:8000

Documentation:

http://127.0.0.1:8000/docs
